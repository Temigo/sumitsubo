# Bundled data

`similar-kanji.txt`: kanji that look alike, one line per kanji: the kanji, then the kanji similar
to it, separated by slashes. A human-made list from the similar-kanji project by siikamiika
(https://github.com/siikamiika/similar-kanji, MIT licence, copyright 2017 siikamiika), which says
it was built around a file of the same name from the program My JWPce. The licence of that original
file has not been checked; confirm it before publishing Sumitsubo more widely.

`jlpt_kanji.json`: the JLPT level of 2,211 kanji, from Jonathan Waller's lists
(https://www.tanos.co.uk/jlpt/; see that site for the terms he shares them under), taken
from the `kanji-lists` package (MIT). The lists are unofficial: no official list has existed
since 2010.
